# BE-011 — API documentation and a health endpoint

**Type:** Docs / DX
**Epic:** BE — Backend correctness & safety
**Affects:** `backend/src/job_assistant/main.py`
**Priority:** P2
**Status:** `PLANNED`

## Summary
The app has no title, version, description, or tags on its OpenAPI schema, no request/response
examples, and no health endpoint. `GET /` returns `{"message": "Hello World"}`, which is scaffold
output, not a useful route.

## Current behaviour
```python
app = FastAPI()                      # no metadata

@app.get("/")
def read_root():
    return {"message": "Hello World"}
```

FastAPI generates a schema automatically at `/docs`, but with no descriptions, no examples, and no
declared error responses it documents almost nothing. There is also no way to check liveness
without spending money on an analysis.

## Why it matters
`/docs` is the fastest way for a reviewer to understand the API without reading code, and it costs
almost nothing to make it good. A health endpoint is table stakes for any deployment (ARCH-003).

## Proposed scope
- Give the app real metadata: title, version, description, contact, and a tag description for the
  job-analysis routes.
- Add `summary` and `description` to the endpoint, with realistic request and response examples in
  `model_config = ConfigDict(json_schema_extra={...})`.
- Declare error responses (`422`, `429`, `502`, `503`) so they appear in the schema, using the
  contract from BE-002.
- Replace `GET /` with `GET /health` returning status, version, uptime, and whether each upstream
  dependency (DeepSeek, TypeSafe) is configured — **without** calling them or spending money.
- Keep `/docs` available in development; decide explicitly whether to disable it in production and
  record the decision.
- Link `/docs` from the README (DOC-001).

## Acceptance criteria
- [ ] `/docs` shows a title, version, endpoint description, and worked examples.
- [ ] Documented error responses appear for the analysis endpoint.
- [ ] `GET /health` returns 200 with dependency configuration status and makes no paid calls.
- [ ] The placeholder `Hello World` route is gone or clearly marked as a liveness check.
- [ ] README links to `/docs` and explains what it shows.
